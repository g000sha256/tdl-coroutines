# Module tdl-coroutines

TDL Coroutines provides a Kotlin Multiplatform coroutine client for TDLib.
The original Kotlin implementation is licensed under the Apache License 2.0.

## Third-party licenses

The API descriptions and parameter documentation are derived from TDLib's
`td_api.tl` schema and distributed under the Boost Software License 1.0.

The native libraries also include OpenSSL and SQLCipher. Android uses
OpenSSL 1.1.1w under the OpenSSL and Original SSLeay licenses; OpenSSL 3.x
uses Apache License 2.0. SQLCipher's included code is covered by its BSD license.
